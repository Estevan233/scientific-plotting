## 2. 语义色彩分配黄金守则

1. **红色专属性（Semantic Red Rule）**：
   - 严禁将明亮鲜红（`#FF1A1A` / `#D62728`）随机赋予普通的某条曲线或某根柱子。
   - **红色的唯一合法用途**：
     - 图像多子图中的 **ROI 局部放大红框**；
     - 阈值分界线（Cutoff / Threshold Line）；
     - 截断警示或极限失效点（Failure / Alert）。
2. **"本文方法 (Ours)" 的视觉引导**：
   - 在柱状图、折线图或雷达图中，给 `Ours` 赋予统一且具主导性的颜色（如 Tol-Muted 深绿 `#117733`、海军蓝 `#0B5394` 或鲜明绿 `#2ECC71`）。
   - 在多方法对比列表中，`Ours` 固定放置在**最右侧（柱图）**或**最下方/最后一列（图像矩阵）**，符合心理学上的压轴预期。
3. **黑白灰度双保险原则**：
   - 永远不要**仅仅依赖颜色**来区分数据系列。
   - 折线图必须配合 **Marker 形状**（圆圈 `o`、正方形 `s`、三角 `^`、菱形 `d`）和 **线型**（实线 `-`、虚线 `--`、点画线 `-.`）。
   - 柱状图在需要黑白印刷时，宜辅以斜线阴影（`hatch='//'`、`hatch='\\\\'`、`hatch='xx'`）。
